# Local analysis outputs

Run `imdb-actor-success analyze --data-dir data --output-dir results` from the repository root for the default 7.0 analysis. Additional local runs use `results/rating-8/` and `results/no-cutoff/`; see the repository README for exact commands. Each contains a leaderboard, movie-level table, report, and summary. All generated tables and reports are excluded from Git. The repository README and SVG figures summarize the October 7, 2026 snapshot.
